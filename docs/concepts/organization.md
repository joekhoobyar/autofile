# Organization

Autofile provides cabinets and tags for organizing documents.

## Cabinets

Cabinets are similar to folders - except that a document is allowed to belong to more than one cabinet. Use cabinets when a document belongs in a defined organizational grouping.

## Tags

Tags are flexible labels. Use tags for cross-cutting categories, workflow states, or attributes that do not need a full document type or metadata field.

## Choosing Between Cabinets and Tags

Use a cabinet when the grouping is a primary filing location. Use tags when the grouping is supplemental, temporary, or likely to overlap with many other groupings.
