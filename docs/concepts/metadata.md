# Metadata

Metadata lets Autofile store structured information about documents.

## Document Types

A document type describes a class of documents, such as invoices, statements, receipts, letters, or contracts.

## Metadata Types

A metadata type defines a reusable field that can be associated with document types. Examples include invoice number, statement date, vendor, account number, or total amount.

## Document Metadata

Document metadata stores values for a specific document. Metadata is useful for filtering, searching, classification, and building document indexes.
